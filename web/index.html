What you can do

Video

Compress or convert to H.264 or H.265 MP4. Set the width, frame rate, audio, or a target file size.

Images

Resize while keeping the original proportions, or convert between JPEG, PNG, WebP, BMP, TIFF, and GIF.

PDF

Turn scans into a PDF or combine images and existing PDFs in the order you choose.

Batch rename

Number files, add a prefix, or replace text. Preview the new names before applying them.

Export Office files to PDF with Word or Excel on Windows, or LibreOffice on macOS and Linux.

10-second walkthrough

From right-click to MP4

  1. Right-click a video in File Explorer.
  2. Choose Convert to MP4 / H.264.
  3. Run the action and open the new file.
