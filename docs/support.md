# Матрица Context Actions 0.1

Это первая рабочая версия, а не подтверждение всех критериев финального релиза из плана. Проверки выполняются программно на маленьких синтетических файлах. Реальные меню Windows, визуальное качество, Narrator, Office и установка/удаление на чистой машине оставлены для ручной проверки пользователя.

| Действие | Вход → выход | Ограничения 0.1 |
| --- | --- | --- |
| Сжатие / H.264 / H.265 | MP4, MKV, MOV, AVI, WebM, M4V, WMV, MTS, M2TS → MP4 | Реальное чтение зависит от кодека внутри контейнера; повреждённые/неподдерживаемые файлы показывают ошибку. Всегда программный libx264/libx265, без зависимости от GPU. Первый видеопоток и первый аудиопоток, AAC 128 кбит/с или без звука. Остальные дорожки и субтитры удаляются. |
| Настройки видео | CRF 0–51, максимальная ширина, FPS, без звука, предел размера в МиБ | Выходные размеры чётные. Лимит размера — отдельный расчёт битрейта с запасом и до четырёх попыток; проверяется фактический размер. При битрейте ниже 64 кбит/с или недостижимом лимите — ошибка без готового файла. Это ограничение максимального размера, не обещание точного количества байт. HDR не входит в подтверждённую матрицу. |
| Telegram | Видео → MP4 H.264 без звука | По умолчанию максимум 720 px и 30 FPS. Клиенты Telegram в этой работе не проверялись; отображение как анимации требует проверки пользователем. |
| Изображения | JPEG, PNG, WebP, BMP, TIFF, GIF → PNG, JPEG, WebP, BMP, TIFF, GIF | Статичный кадр. Для GIF/TIFF/WebP нужно явно разрешить первый кадр/страницу, включая PDF. Масштабирование сохраняет пропорции и не увеличивает изображение. CRF-подобный общий параметр 0–51 для потерь: ниже лучше; PNG/BMP/TIFF/GIF его игнорируют. Метаданные и ICC-профили не сохраняются; FFmpeg применяет распознанный поворот. JPEG/BMP/PDF заполняют прозрачность белым. Форматы HEIF/AVIF не заявлены. |
| PDF из изображений / объединение | Упорядоченный набор изображений и PDF → один PDF | Порядок файлов показан в списке и меняется кнопками «Выше/Ниже». Все страницы каждого входного PDF сохраняются в исходном порядке. Изображения — JPEG на A4 с полями 24 пт, автоматическая портретная/альбомная ориентация; оригинальные PDF сохраняют размер страниц. qpdf не объединяет формы, подписи, закладки/структуру документов. Защищённые PDF без доступного пароля дают ошибку. При сбое одного входа весь объединённый результат не публикуется. |
| Переименование | Любые выбранные обычные файлы → новые имена в тех же папках | Шаблон `{name}` и `{n}`, префикс/суффикс, замена подстроки, начальный номер; расширение сохраняется. Перед запуском обязателен предпросмотр. Конфликты, зарезервированные имена, обмен имён и циклы отклоняются до начала. При обычной ошибке выполненные перемещения откатываются. |
| Отмена переименования | Последнее завершённое переименование → исходные имена | При сохранении файлов с прежними размером и временем изменения и свободных исходных именах. Это базовая проверка, не хеширование содержимого. При аварии процесса остаётся `rename-pending.txt` с путями для ручного восстановления; последующие переименования блокируются до разрешения этого журнала. Автоматического восстановления после отключения питания нет. |
| PDF через Word | DOCX, DOC, ODT, RTF, TXT → PDF | Нужен установленный Word с поддержкой входного формата. Используется отдельная COM-сессия, файл только для чтения, без макросов/добавления в недавние. Парольные документы не поддерживаются. Сохранность полного оформления на пользовательских файлах не проверена. |
| PDF через Excel | XLSX, XLS, ODS, CSV → PDF | Нужен установленный Excel; макросы, обновление ссылок и добавление в недавние отключены. Экспорт книги с её областями печати. Выбор листов и настройка печати не включены в 0.1. |
| Автономные документы / таблицы | Пока недоступно | Согласованный следующий этап: движок, сохранение формул/оформления, листы и CSV-настройки. Office не заменяет этот обязательный будущий набор. |

Word и Excel хранят отдельные состояния unknown/available/unavailable в `%LOCALAPPDATA%\Context Actions\capabilities.ini`. До первой попытки COM не создаётся. Ошибка запуска Office меняет состояние, ошибка отдельного файла — нет. «Проверить снова (Office)» сбрасывает состояния; следующая выбранная операция заново проверяет нужное приложение. Отмена Office ожидает возвращения текущего COM-вызова; чужие процессы Office не завершаются.

Преобразования выполняются последовательно в рабочем потоке, с общим прогрессом и статусом каждого файла. Ошибка отдельной конвертации не останавливает следующие файлы. Имена совпавших выходов получают `(2)`, `(3)` и далее. Результат записывается во временный каталог рядом с выходом и переносится в окончательное имя без перезаписи после успешного движка и проверки. Отмена FFmpeg/qpdf завершает только созданное дерево дочернего процесса и удаляет временный каталог.

Меню и UI имеют EN/RU/DE/FR/zh-CN с английским резервным переводом. Используются системные элементы, системный шрифт, PerMonitorV2 DPI, прокрутка при небольшом окне, клавиатурная навигация и системный высокий контраст. Светлая/тёмная тема меняет фон приложения и списка; часть стандартных кнопок/комбобоксов сохраняет системное оформление. Ручные проверки доступности, 100–200% DPI и полировка оформления ещё не выполнены.

`--headless` предназначен для программной обработки/тестов и не показывает UI. Он требует `--report`; код 0 означает успех, 1 — ошибку, 2 — отмену. Все ограничения и защита исходников общие с GUI.
